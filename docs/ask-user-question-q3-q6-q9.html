教學重點

  • 選項全部來自實際掃描到的圖層；圖面沒有 COL_NAME，所以不會出現這個選項。

教學重點

  • Q6 需要自由輸入，所以用 Ask User Question 內建的「Type something.」欄位貼上多列資料。
  • 先解析、再套用。成功、重複、缺值、無法識別四類要分開列出，不能默默略過。
  • 對照表尺寸還要與 COL-L 幾何交叉比對；不一致的柱標為「資料矛盾」，不進入交易。
  • 80x60 與 60x80 分別正規化為 W80 H60 與 W60 H80，不自動互換。

教學重點

  • Q9 之前一定要先顯示預覽與摘要，使用者看得到會建立什麼、不會建立什麼。
  • 選項說明直接寫出後果（建立幾根、寫入哪個欄位），避免使用者猜測。
  • 只有選「建立」才開啟 Transaction；「返回修正」與「取消」都不能修改模型。
  • 資料矛盾、無類型、無編號、排除的柱不會被計入成功。
